Athlete Performance Reporting System

Project Overview

This project is an Excel-based dashboard designed to analyze athlete performance data through reporting and visual analytics.

Features

* Raw data organization
* KPI tracking
* Player performance analysis
* Dashboard visualizations
* Touchdown and yard comparisons
* Position breakdown charts

Tools Used

* Microsoft Excel
* Data Analysis
* Charts and Visualizations

Skills Demonstrated

* Data organization
* Reporting
* Dashboard creation
* Analytical thinking
* Systems analysis concepts

Future Improvements

* Convert dashboard into Power BI
* Add SQL database integration
* Add automated reporting features
